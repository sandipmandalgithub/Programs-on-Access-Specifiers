# Java Access Specifier Programs

This repository contains Java programs demonstrating the use of access specifiers in Java.

The programs are intended for practicing and understanding access control in Object-Oriented Programming (OOP).

## 📚 Concepts Covered

* `public` access specifier
* `private` access specifier
* `protected` access specifier
* Default (package-private) access
* Access control in Java classes and members

## 🛠️ Technologies Used

* **Programming Language:** Java
* **IDE:** Eclipse IDE (if applicable)
* **Concept:** Object-Oriented Programming (OOP)

## 🚀 How to Run

1. Clone or download this repository.
2. Open the Java source files in Eclipse IDE or another Java IDE.
3. Configure a Java project if required.
4. Run the desired Java class as a Java Application.

## 🎯 Purpose

This repository was created for Java programming practice and to strengthen my understanding of access control and OOP concepts.
